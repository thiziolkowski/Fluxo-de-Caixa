# Fluxo-de-Caixa

Projeto criado em Node Next com uso do banco MySQL

- Saldo incial do sistema fixado no código.
- Opções de incluir e excluir lançamento
- Opção de ajustar status de pagamento
- Opção de filtro por descrição. Ex: Filtrar "consultoria"

- O presente projeto pode ser usado para simples controle de receitas e despesas e saldo bancário.
